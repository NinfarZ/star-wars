# Star Wars Data Explorer

A React app for browsing the Star Wars universe using the [SWAPI](https://swapi.dev) public API.

## Tech Stack

- **React 19** + **TypeScript**
- **Vite** — dev server and build tool
- **React Router v7** — client-side routing
- **TanStack Query v5** — data fetching and caching
- **Tailwind CSS v4** — styling

## Features

- Browse all 6 SWAPI resource types: Films, People, Planets, Species, Vehicles, Starships
- Paginated list views for each resource
- Detail pages with linked related resources
